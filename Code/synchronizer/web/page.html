Width and offset (placement from the drive coil's centre) per direction, used by KICK's own pulses. Advance speeds up a slow clock; retard slows down a fast one. An attract-only coil retards far more strongly than it advances, so each side usually wants its own width. 0 disables that direction's corrections entirely. The test pulse above is a manual one-off with its own width, unrelated to either. Use FORCEERR on the console to trigger KICK on demand and watch which way a placement actually moves the clock.
