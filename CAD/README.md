# CAD

FreeCAD models for the coil and electromagnet holders, all designed by
Daniel Marks for this project. Each has a base cup for ballast (rocks, steel
shot, cement, ...) so the holder stands still on its own rather than picking
up the pendulum's vibration.

| File | Role |
|---|---|
| `WeightedCoilForm.FCStd` | The sense/drive coil holder, including the form the magnet wire is wound on. |
| `WeightedElectromagnetHolder.FCStd` | The platform that holds the drive electromagnet — in the photos, a 50 mm × 35 mm, 500 N lifting magnet, 12 V at about 250 mA. |
| `CoilBobbin.FCStd`, `CoilForm.FCStd`, `CoilFormWithPCBHolder.FCStd`, `CoilFormWithPCBHolder2.FCStd` | Earlier coil-form and PCB-holder designs. |

STLs are the printable exports of the corresponding model; `.FCBak` files are
FreeCAD's own backups and can be ignored.
